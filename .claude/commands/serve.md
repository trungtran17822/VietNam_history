Run `npm run dev:frontend` (Vite on http://localhost:8080) and `npm run dev:backend` (class session API on :8787) from the repo root, each in the background, then tell me to open http://localhost:8080. Needs node >= 20.19. Do not start a second server on a port that is already in use.
