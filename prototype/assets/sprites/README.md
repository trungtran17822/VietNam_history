# Illustrated Map Sprite Slots

Place transparent PNG artwork here to replace the renderer's procedural silk-map markers. Files are loaded locally from this folder; absent files keep the procedural drawings.

| Filename | Marker | Recommended canvas |
| --- | --- | --- |
| `soldier_a.png` | Side A soldier | 256 x 256 px |
| `soldier_b.png` | Side B soldier | 256 x 256 px |
| `elephant.png` | Elephant marker | 384 x 384 px |
| `tent.png` | Tent marker | 256 x 256 px |
| `banner_a.png` | Vermilion banner | 256 x 256 px |
| `banner_b.png` | Indigo banner | 256 x 256 px |
| `palisade.png` | Palisade segment | 384 x 256 px |
| `watchtower.png` | Watchtower marker | 256 x 256 px |
| `torch.png` | Torch marker | 256 x 256 px |
| `village.png` | Village-roof cluster | 384 x 256 px |
| `bamboo.png` | Bamboo cluster | 384 x 384 px |

Use a transparent background, hand-painted ink contours, and muted fills. Keep the visual angle close to a top-down map symbol so the image sits naturally on the map plane. Faction pigments and all costume details are illustrative placeholders pending historian review; no historical accuracy is implied.
