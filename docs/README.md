# Docs

- `prd/` - Product requirements and demo roadmap (.docx).
- `spec/` - `SPEC.md` (English) and `SPEC.vi.md` (Vietnamese): requirements, status against the prototype, as-built contract, schedule.
- `sources/` - Primary source material (textbook PDF). Cited from `prototype/data/sources.json`.

Add new documents under a matching subfolder (e.g. `adr/` for architecture decisions, `design/` for mockups).
