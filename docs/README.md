# Docs

- `prd/` - Product requirements and demo roadmap (.docx).
- `spec/` - `SPEC.md` (English) and `SPEC.vi.md` (Vietnamese): requirements, status against the build, as-built contract, schedule.
- `srs/SRS.md` - Software Requirements Specification (Vietnamese, ISO/IEC/IEEE 29148 layout), traced to `specs/001-classroom-sim-demo/spec.md`.
- `architecture/SYSTEM_DESIGN.md` - System design: context, components, API, deployment, security, ADR summary.
- `design/UI_REVIEW.md` - UI audit (impeccable + Playwright, 3 rounds) and the layout decisions.
- `devops/` - `DEPLOY.md` (Vercel + Cloudflare runbook) and the earlier CI/CD note.
- `research/` - Background research reports (.docx).
- `brand/` - Original logo files (the app ships a reduced copy).
- `sources/` - Primary source material (textbook PDF). Cited from `frontend/data/sources.json`.

The feature spec, plan, data model and API contract live in `specs/001-classroom-sim-demo/`.
