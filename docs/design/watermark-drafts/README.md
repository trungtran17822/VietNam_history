# Bản nháp hình mờ (watermark) - chưa gắn vào ứng dụng

- `option-a-flag-embossed.svg`: Quốc kỳ dạng chìm nổi (nổi nhẹ, có bóng trong và viền sáng), gần gũi, dễ nhận ra nhất.
- `option-b-flag-inset.svg`: Quốc kỳ dạng chìm (như ép lõm vào giấy), rất mờ, ít gây xao nhãng khi đọc.
- `option-c-dong-son-drum.svg`: Họa tiết trống đồng Đông Sơn tự vẽ (nguyên bản, giản lược), gợi chất lịch sử - văn hóa, không dùng quốc kỳ.

## Cách chọn
- Muốn thể hiện rõ chủ quyền/quốc gia: chọn A (nổi rõ hơn) hoặc B (kín đáo hơn).
- Muốn nền nhẹ nhất cho trang nhiều chữ: chọn B hoặc C.
- Muốn tránh quy định về sử dụng quốc kỳ làm nền trang trí: chọn C.
- Tất cả dùng độ mờ 0.10-0.16, nền kem; thử trên màn hình lớp học (máy chiếu) trước khi chốt.
