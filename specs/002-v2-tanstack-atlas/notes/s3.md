# S3 - Atlas Việt Nam 3D (`Dat/feature/v2-atlas`)

Nhật ký của session S3. S3 chạy **song song** với S1 (Đạt cho phép, đĩa đủ cho một worktree nữa), trong
worktree riêng, nhánh cắt từ `Dat/feature/core` (không có code S1). Chỉ chạm các đường dẫn atlas (xem
"Phạm vi"), để S4 gộp nhánh không đụng phần S1 viết lại.

## Kế hoạch

Đã đọc: `plan.md` §1, §2, §4.2, §5; `CLAUDE.md`; `.claude/rules/*`; `frontend/js/scene-map.js` (palette từ
CSS, sprite canvas, `InstancedMesh`, nhãn HTML, `destroy()`); báo cáo GeoGnos §4.1 (chấm điểm tìm kiếm),
§4.2 (lọc), §7 (URL state), §14 (không chép nội dung GeoGnos).

1. **Dữ liệu (pha A)**, `scripts/atlas/` (node, tải thô vào `scripts/atlas/.raw/`, gitignore):
   `build-boundaries.mjs` → `provinces.topo.json`; `build-terrain.mjs` → `public/atlas/terrain.png`;
   `build-landmarks.mjs` làm giàu `landmarks.json` (toạ độ Wikidata, `provinceId`, nguồn + giấy phép).
   `SOURCES.md` trong `frontend/src/content/atlas/`.
2. **Test** `tests/atlas/*.test.mjs` (`node --test`, Node ≥ 22.18 chạy thẳng `.ts`): 34 đơn vị, hai quần
   đảo, landmark nằm trong tỉnh, id kebab-case duy nhất, chuỗi NFC, ngân sách dung lượng, `search.ts`.
3. **Renderer (pha B)** `frontend/src/features/atlas/scene.ts` (`VietnamAtlasScene`, không phụ thuộc
   framework), `search.ts`, `AtlasView.tsx`, route `frontend/src/routes/atlas.tsx`.
4. **Đo 2-3 phương án** địa hình/ranh giới, chọn phương án tốt nhất (bảng ở dưới).
5. **Harness** `scripts/atlas/harness/` (Vite + Playwright): ảnh chụp desktop 1280×720, phone 360×800,
   FPS, kích thước chunk.
6. **Docs**: mục atlas trong `SPEC.md`, `SPEC.vi.md`, `SRS.md`, `SYSTEM_DESIGN.md`; ghi chú cho S4.
